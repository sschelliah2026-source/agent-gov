agent-gov Architecture

AI Agent Cost Governance — Budget Enforcement, Tool Registry, Multi-Tenant Workspaces

Budget Enforcement

  • Per-agent daily budgets
  • Auto-pause on overage
  • Manual resume endpoint
  • Daily auto-reset at midnight

Tool Registry

  • Register tools with real costs
  • Proxy uses real cost, not estimate
  • 24 pre-configured tool presets
  • Per-tool analytics dashboard

Multi-Tenancy

  • Workspace isolation
  • Separate agents, tools, budgets
  • Dashboard filtered by workspace
  • Default workspace for backward compat
